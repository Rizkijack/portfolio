Multi-agent world

SlopAgentbook

2026
Source ↗ Live town ↗

The town runs on the server. Every resident, called The Shorn, is a pixel livestock agent with a nine-segment DNA that draws its sprite. Fork one and the child inherits that DNA with measured mutations. Decisions come from a rule table in simbrain.ts covering survive, drink, eat, seek company, wander, take a quest and head to a named building. Nothing leaves the process, so a decision costs nothing and cannot fail on a quota. Another brain can be injected through createBrain, and if it throws, the rule table takes over.

Residents keep memory and relationships, so they can quote back what they remember about you. The Daily Spit, the in-world newspaper, publishes on a schedule. BRAWL sits above the town as a Solana Mainnet trading rail with scoped wallets, a leash for per-trade limits and stop-loss or take-profit, pay-on-profit settlement, a ledger and hiscores. There is no token mint or on-chain reserve behind the treasury figures. Those come from /api/treasury as an illustrative balance.

The stack is a pnpm workspace with an Express and TypeScript backend, a React and Vite hash-routed frontend, shared TypeScript contracts, an MCP server and server-sent events for the live snapshot. Persistence is data/town.json locally, and Postgres with Supabase primary plus a Prisma standby when DATABASE_URL is set.

Web stack analysis

Reascan

2026
Live site ↗ GitHub repository ↗

Paste a URL into Reascan and it returns an evidence-standard report instead of a score. The sample on the landing page shows a fingerprint table with columns for key, value, type and confidence. It lists the server as nginx/1.25.3 with observation and high confidence, the CDN as Cloudflare with observation and high, and the framework as Next.js 14.2.3 with derivation and medium. Limitations and unknowns stay in the report.

The request travels through five hops: the browser, a Pages Function at the edge, a Cloudflare Tunnel, an adapter server on the VM, and the analysis modules. Findings cover web stack fingerprinting, JavaScript bundles, browser capture and deeper analysis, all rendered on one page. The frontend is on Cloudflare Pages while the analysis runs on a private VM, which keeps the heavy work off the edge.

AI chat

Echo

2026
Live site ↗ GitHub repository ↗

Echo is an AI chat with a procedural midnight city behind it. The city draws itself building by building, and the camera moves only when you scroll, so it waits for you instead of performing. You talk to Beam, Reflection’s open 501B model, in one continuous conversation. Its thinking stays in collapsible blocks, which lets you read the reasoning next to the answer.

Every day starts with two free credits. More come from top-ups on Base with USDC or on Robinhood Chain with USDG, verified on-chain with no middleman. The app runs in six languages on one model. Underneath, a single-file public/index.html handles the interface with no build step, and a Cloudflare Worker proxies POST /api/chat to Reflection using Beam-1.0-501B-A23B. The provider key lives only in the Worker secret. If the proxy is down, the page falls back to built-in simulated replies.

The dashboard keeps account summary, usage per model, credits, backups and settings on one page. API keys are created there in the dashboard, stored in KV and shown in full once at creation, with a maximum of ten per wallet. The OpenAI-compatible endpoint accepts streaming and non-streaming requests, and CORS is open so browser clients can call it directly.
